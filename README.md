# Program Analisis Tingkat Stress Mahasiswa Teknik
### SDG 3 – Good Health and Well-Being

Program berbasis bahasa C untuk menganalisis tingkat stres mahasiswa teknik berdasarkan jam tidur, beban aktivitas, resting heart rate, hobi, dan pembinaan kultural kampus.

---

## Latar Belakang

Mahasiswa teknik sering menghadapi tekanan akademik, organisasi, dan aktivitas kampus yang tinggi. Jika tidak dikelola dengan baik, kondisi tersebut dapat memengaruhi kesehatan mental, kualitas tidur, hingga performa belajar.

Program ini dibuat sebagai bentuk implementasi **SDG 3 (Good Health and Well-Being)** untuk membantu mahasiswa melakukan self-assessment sederhana terhadap kondisi stres mereka.

---

## Fitur Program

- Analisis tingkat stres mahasiswa
- Sistem rekomendasi otomatis
- Statistik hasil analisis
- Penyimpanan data mahasiswa
- Riwayat seluruh hasil tes
- Referensi jurnal kesehatan mental
- Validasi input pengguna

---

## Faktor Analisis

Program melakukan analisis berdasarkan beberapa indikator:

| Indikator | Penjelasan |
|---|---|
| Durasi Tidur | Menilai kualitas dan durasi tidur mahasiswa |
| Beban Aktivitas | Total jam kuliah, organisasi, dan pembinaan |
| Resting Heart Rate | Mengukur indikasi stres dari denyut jantung |
| Hobi | Menilai keseimbangan aktivitas pribadi |
| Pembinaan Kultural | Mengukur pengaruh kegiatan kampus terhadap stres |

---

## Tingkat Stres

Hasil analisis dibagi menjadi 3 kategori:

- Rendah
- Sedang
- Tinggi

Program juga memberikan rekomendasi otomatis sesuai kondisi pengguna.

---
